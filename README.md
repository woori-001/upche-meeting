# 업체회의 누적분석

협력점·판매점·제휴 업체의 월별 접수 실적, 신규·이탈, 증감, 취소율·해지율을 보는 웹앱입니다.

- **화면**: 이 저장소의 `index.html` (깃허브 페이지로 공개)
- **데이터**: 구글시트 `업체회의v1` + 시트에 붙은 Apps Script(`apps-script/Code.gs`)
- **로그인**: 구글시트의 `계정` 탭에 등록한 아이디·비밀번호

## 파일

| 파일 | 내용 | 바꾸는 곳 |
|---|---|---|
| `index.html` | 화면 전체 (디자인·계산·엑셀 저장) | 이 저장소 |
| `apps-script/Code.gs` | 로그인 확인, 시트 읽기·쓰기 | 구글시트 → 확장 프로그램 → Apps Script |

## 처음 설정 (한 번만)

### 1. Apps Script 서버
1. 구글시트 `업체회의v1` → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣고 저장
3. 예전에 쓰던 `index` HTML 파일은 지워도 됩니다(화면은 이제 깃허브에서 엽니다)
4. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
5. 복사한 주소를 브라우저 새 탭에 붙여넣어 한 번 엽니다 → 시트에 `계정` 탭이 생깁니다

### 2. 계정 등록
구글시트 `계정` 탭에 한 줄에 한 명씩 적습니다.

| 아이디 | 이름 | 비밀번호 | 사용 | 마지막로그인 |
|---|---|---|---|---|
| kim | 김OO | 1234 | | |

- 비밀번호는 처음에 그냥 적어두면, **첫 로그인 때 자동으로 암호화**되어 `sha256$…` 로 바뀝니다.
- 비밀번호를 잊으면 그 칸을 지우고 새 비밀번호를 그냥 적으면 됩니다.
- 사용 칸에 `N` 을 적으면 그 계정은 로그인할 수 없습니다.
- 로그인한 뒤 화면 왼쪽 아래 **[비밀번호]** 로 각자 바꿀 수 있습니다.

### 3. 화면 주소 연결
`index.html` 에서 아래 한 줄의 `__API_URL__` 을 1-4에서 복사한 주소로 바꿉니다.
```js
const DEFAULT_API_URL = "__API_URL__";
```
(깃허브에서 `index.html` → 연필 아이콘 → 검색(Ctrl+F)으로 찾아서 바꾸고 **Commit changes**)

바꾸기 전에도 로그인 화면의 **[연결 설정]** 에 주소를 넣으면 그 브라우저에서는 바로 쓸 수 있습니다.

### 4. 깃허브 페이지 켜기
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**
1~2분 뒤 `https://woori-001.github.io/upche-meeting/` 로 열립니다.

## 수정할 때
- 화면만 바뀔 때: `index.html` 만 교체(깃허브에서 **Add file → Upload files** 로 끌어다 놓기) → 1~2분 뒤 새로고침
- 서버가 바뀔 때: `apps-script/Code.gs` 를 Apps Script에 붙여넣고 **배포 관리 → 새 버전** (주소는 그대로)

## 보안
- 깃허브 페이지는 누구나 열 수 있지만, 데이터는 **로그인해야만** 서버가 내려줍니다(로그인 유지 6시간).
- 시트의 `고객키` 칸에는 재접수 판정용으로 연락처 앞 7자리 + 가린 이름만 저장됩니다.
- 구글시트 자체의 공유 범위는 관리자만으로 두세요.
