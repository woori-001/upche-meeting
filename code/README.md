# 코드실적 계산기 (SKYLIFE / SKB / SK매직)

`index.html` — 브라우저에서 바로 열어 쓰는 단일 파일 계산기.
상부정산 / 전체정산 로우데이터를 **전체 그대로** 넣어도 상부점 코드로만 골라 집계합니다.

## 집계 대상 상부점 코드 (정확 일치)

| 브랜드 | 구분 | 상부점 | 상품명 조건 |
|---|---|---|---|
| SKYLIFE | 유선 | `1.유SKY-우리(월☆통25)` | 인터넷 / TV / 부가상품 |
| SKYLIFE | 무선 | `1.무SKY-우리(월☆통25)` | `모바일_SKYLIFE` |
| SKB | 유선 | `6.유SKB-웨이브넷(월☆통말)` | 인터넷 / TV / 부가상품 |
| SKB | 무선 | `6.무SKB-웨이브넷(월☆통말)` | `모바일_SKB` |
| SK매직 | 렌탈 | `2.렌탈SK매직-우성(월☆통말)` | `렌탈_SK매직` |
| 유선기타 | 유선 | 숫자로 시작하지 **않는** 상부점 | `유선기타_*` 전체 |

`백메가SKY(주★통금)`, `3.유SKY-우신(월☆통25)` 등 유사 코드는 집계에서 제외됩니다.

## 유선기타 (별도 카테고리)

상품명이 `유선기타_` 로 시작하는 모든 행. SK-biz · KT-biz · LG-biz · 다회선을 모두 담습니다.

**건수는 (상부점 + 고객명) 묶음 = 1건.** 상부점이 다르면 다른 건으로 셉니다.

| 고객 상황 | 행 | 집계 |
|---|---|---|
| 인터넷 + CCTV 동시 신청 | 2행 | **1건** · 대표 인터넷 |
| 인터넷전화만 2대 | 2행 | **1건** · 대표 인터넷전화 |
| CCTV만 | 1행 | **1건** · 대표 CCTV |

대표 상품 우선순위: **인터넷 → CCTV → 인터넷전화 → TV → 일반전화 → 부가상품 → 기타**.
인터넷이 없으면 CCTV로, CCTV도 없으면 인터넷전화로 1건 잡습니다.

`다회선`은 묶지 않고 **행당 1건**.

유선기타는 수입−지출 수익만 계산하고 **자점마진·유지수수료는 붙지 않습니다.**

### 코드입력 건 제외

**상부점이 숫자로 시작하면 우리 코드로 입력된 건**이므로 유선기타에서 제외합니다.

```
0.기타                      1.유SKY-우리(월☆통25)         3.유SKY-우신(월☆통25)
1.무KT-우리(유심)(월☆통말)    2.렌탈SK매직-우성(월☆통말)     5.무KT-대성_*(월☆통20)
1.무SKY-우리(월☆통25)        2.무SKT-우성(1702/1706)      5.유KT-대성_*(월☆통20)
1.유KT-우리(도매)(동판O)      2.유SKT-우성(1702/1706)      6.무SKB-웨이브넷(월☆통말)
1.유KT-우리(온라인)(월☆통15)  3.유KT-우신(유선기타)(월☆통20)  6.유SKB-웨이브넷(월☆통말)
1.유KT-우리(유선기타)(월☆통15) 3.유KT-우신(현장)(월☆통말)
```

`6.유SKB-웨이브넷(월☆통말)` 도 우리 코드라 유선기타에서 빠지고 SKB에 잡힙니다.

집계 대상은 숫자로 시작하지 않는 상부점뿐입니다 — `디컴스(월☆통15)`,
`광합성(주★통금)`, `새용마(주★통금)`, `지엠컴퍼니(주★통금)`, `더베이스(월☆30일)`,
`한결위드(월☆통말)`, `타임(주★통금)`, `KT라인/그린파머(월☆통말)`,
`아진정보통신(월☆통20)`, `케이티텔레캅(월☆통25)` 등.

## 상품 분류 (행 단위 — 고객 단위로 묶지 않음)

판정은 위에서부터 순서대로. `CCTV`는 문자열에 'TV'를, `인터넷전화`는 '인터넷'을
포함하므로 반드시 먼저 걸러냅니다.

| 상품 | 판정 | 자점마진 | 유지수수료 |
|---|---|---|---|
| CCTV | `/CCTV/i` | 없음 | 없음 |
| 인터넷전화 | `/인터넷전화/` | 없음 | 없음 |
| 일반전화 | `/일반전화\|_전화$/` | 없음 | 없음 |
| TV | `/TV/` | 없음 | 적용 |
| 인터넷 | `/인터넷/` | **적용** | 적용 |
| 부가상품 | `/부가상품/` | 없음 | 없음 |
| 기타 | 나머지 | 없음 | 없음 |

**인터넷전화는 인터넷이 아닙니다.** 건수·유지수수료·자점마진 어디에도 인터넷으로
잡히지 않는 별개 상품입니다. CCTV도 마찬가지입니다.

## 자점운영마진 (협력점 `1.시흥영업팀` / `2.천안영업팀`, 전체정산 기준)

| 항목 | 건당 |
|---|---|
| SKYLIFE 유선(인터넷) | 100,000원 |
| SKYLIFE 무선(유심) | 50,000원 |
| SKB 유선(인터넷) | 100,000원 |
| SKB 무선(유심) | 100,000원 |
| SK매직 렌탈 | 없음 |

자점마진은 **인터넷 + 모바일(유심)** 건수에만 붙습니다.
TV · 부가상품 · CCTV · 인터넷전화 · 일반전화에는 붙지 않고, SK매직 렌탈과
SK-biz 기타에도 붙지 않습니다. 단가는 화면에서 수정 가능.

## 유지수수료 (예상관리)

|---|---|---|---|---|
| SKYLIFE | 950 | 400 | 1,400 | 28 |
| SKB | 1,350 | 800 | 1,500 | 28 |
| SK매직 렌탈 | 없음 | | | |

## 집계 제외 규칙 (화면에서 On/Off)

- `_정산관련` · `_추가지급` 행 제외 (기본 On)
- `_관리` (관리수수료) 행 제외 — 예상관리와 이중계상 방지 (기본 On)
- 개통상태에 `해지` 포함 행 제외 (기본 On)
- 정산종류 `일반`만 집계 (환수·추가 제외, 기본 On)
- SKB `유선기타_(SK-biz)` 포함 (기본 On)

## v7 → v8 변경점

1. **SKYLIFE 제외 규칙 오타 수정** — v7은 `SkyLife_정산관련` / `SkyLife_추가지급`로 비교했으나 실제 데이터는 `SKYLIFE_...` 라 제외가 전혀 동작하지 않았습니다. 8월 데이터 기준 `SKYLIFE_정산관련` −16,501,380원이 수입(A)에 섞여 들어갔습니다.
2. `_관리` 행 제외 옵션 추가 (예상관리와 이중계상 방지).
3. 상부점/상품명 비교 시 공백·NBSP 정규화 → 파일별 공백 차이로 인한 누락 방지.
4. 상부정산/전체정산 파일이 바뀌어 업로드되면 시트명으로 감지해 자동 교정.
5. **조건 체크 리포트** 추가 — 브랜드별 매칭 행수, 제외된 행(상품명·사유·금액), 집계에서 빠진 상부점 목록 표시.
6. 자점마진 단가를 화면에서 수정 가능하도록 변경, 유선은 인터넷에만 적용됨을 명시.
7. 대시보드 기준월을 오늘 날짜가 아닌 데이터의 `정산예정일`에서 산출.
8. 엑셀 보고서에 `적용조건` · `조건체크` 시트 추가.

## v8 → v9 변경점

1. **상품 분류를 행 단위 규칙으로 재작성.** 기존에는 `상품명.includes('인터넷')` 한
   줄로 판정해 `인터넷전화`가 인터넷 회선으로 오분류됐습니다. 이번 달 SKB 웨이브넷에는
   0건이라 숫자 변동은 없었으나, LG-biz 인터넷전화만 상부 46건·전체 48건이 있어
   상부점이 바뀌면 바로 건수·유지수수료·자점마진이 잘못 붙는 구조였습니다.
2. `CCTV`·`인터넷전화`·`일반전화`를 각각 별개 상품으로 집계하고 카드에 건수 표시.
3. **자점마진 대상을 `margin:true` 상품(인터넷)으로 한정.** 문자열 포함이 아닌
   분류 결과로 판정합니다.
4. **SK-biz 기타 카드 추가.** 웨이브넷 외 상부점의 `(SK-biz)` 상품을 상품별로 집계.
   자점마진·유지수수료 없이 수입−지출 수익만 계산합니다.
5. 조건 체크 리포트에 `상품 분류별 건수` 표 추가, 엑셀 `적용조건` 시트에 분류 규칙 수록.

## v9 → v10 변경점

1. **유선기타를 별도 카테고리로 승격.** 기존 `SK-biz 기타` 카드를 유선기타 전체
   (SK-biz · KT-biz · LG-biz · 다회선)로 확장하고 통신사별·대표상품별로 나눠 표시합니다.
2. **건수를 (상부점 + 고객명) 묶음 = 1건으로 집계.** 인터넷전화만 여러 대인 고객도 1건,
   인터넷+CCTV를 같이 신청한 고객도 1건(대표 인터넷)입니다. 상부점이 다르면 별개 건입니다.
3. 대표 상품 우선순위 도입 — 인터넷이 없으면 CCTV, CCTV도 없으면 인터넷전화로 1건.
4. `다회선`은 묶지 않고 행당 1건.
5. 유선기타에는 자점마진·유지수수료가 붙지 않음을 코드와 화면에 명시.
6. **코드입력 판정을 상부점 하나로 단일화** — 상부점이 숫자로 시작하면 제외.
   기존의 `주 상부점 제외` · `다회선 제외` 두 옵션을 이 규칙 하나로 대체했습니다.
   조건 체크 리포트에 제외된 상부점과 행수를 표로 표시합니다.

## 환수 체크 (수익 계산과 별개)

**상부정산**에서 정산종류가 `환수`인 행 중 **우리 코드만** 모아 금액을 확인합니다.
수익(A−B)에는 영향을 주지 않습니다.

| 구분 | 상부점 (우리 코드) |
|---|---|
| SKYLIFE | `1.유SKY-우리(월☆통25)` · `1.무SKY-우리(월☆통25)` |
| SKB | `6.유SKB-웨이브넷(월☆통말)` · `6.무SKB-웨이브넷(월☆통말)` |
| SK매직 렌탈 | `2.렌탈SK매직-우성(월☆통말)` |

- 전체정산의 환수는 보지 않습니다.
- `3.유SKY-우신`, `백메가SKY` 처럼 브랜드는 같아도 우리 코드가 아니면 제외하고,
  제외한 건수만 안내 문구로 표시합니다.
- 해지 제외 · 정산관련 제외 같은 집계 규칙은 적용하지 않습니다.
- **`환수만 체크` 버튼**은 상부정산 파일 하나만 있어도 동작합니다.
  계산하기를 누르면 함께 표시되고, 보고서 엑셀에 `환수` 시트가 추가됩니다.
