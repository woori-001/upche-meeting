유선기타 집계 규칙 (별도 카테고리)
· 대상: 상품명이 유선기타_ 로 시작하는 모든 행 (SK-biz · KT-biz · LG-biz · 다회선)
· 건수는 (상부점 + 고객명) 묶음 = 1건. 인터넷전화만 2대여도 1건, 인터넷+CCTV를 같이 신청해도 1건. 상부점이 다르면 다른 건으로 셉니다.
· 대표 상품 우선순위: 인터넷 → CCTV → 인터넷전화 → TV → 일반전화 → 부가상품 → 기타. 인터넷이 없으면 CCTV로, CCTV도 없으면 인터넷전화로 1건 잡습니다.
· 코드입력 건은 제외. 상부점이 숫자로 시작하면(0. 1. 2. 3. 5. 6. …) 우리 코드로 입력된 건이라 유선기타에서 뺍니다. 6.유SKB-웨이브넷(월☆통말) 도 우리 코드라 여기서 빠지고 SKB에 잡힙니다.
· 숫자로 시작하지 않는 상부점(디컴스, 광합성, 지엠컴퍼니, 더베이스, 한결위드 …) 만 집계합니다.
· 다회선은 묶지 않고 행당 1건.
· 수입−지출 수익만 계산하고 자점마진·유지수수료는 붙지 않습니다.

· 판정 순서가 위에서부터입니다. CCTV는 문자열에 'TV'를, 인터넷전화는 '인터넷'을 포함하므로 인터넷·TV보다 먼저 걸러냅니다.
· 인터넷전화는 인터넷이 아닙니다. 건수·유지수수료·자점마진 어디에도 인터넷으로 잡히지 않습니다.
